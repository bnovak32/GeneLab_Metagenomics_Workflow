Data were processed {% if sample_type == "low_biomass" %}as described in GL-DPPD-{{ pipeline_number }}{{ pipeline_version }} (https://github.com/nasa/GeneLab_Data_Processing/blob/master/Metagenomics/Low_Biomass/Pipeline_GL-DPPD-{{ pipeline_number }}_Versions/GL-DPPD-{{ pipeline_number }}{{ pipeline_version }}.md) {%endif %}using workflow NF_MetagenomeSeq v{{ workflow_version }} (https://github.com/nasa/GeneLab_Metagenomics_Workflow/blob/v{{ workflow_version }}/README.md). 
Quality assessment: Quality assessment of raw, filtered, trimmed, blanks-removed and human-removed reads was performed with Nanoplot v{{ nanoplot_version }} and reports summarized with MultiQC v{{ multiqc_version }}. 
{% if concat %}
Reads concatenation: {% if sample_type == "standard" %}Pre-{% endif %}demultiplexed reads were concatenated by barcode to form raw per sample fastq files. 
{% endif %}
Quality control: raw concatenated reads were filtered by quality (Phred quality >= 8) and length (>=200bp) using filtlong v{{ filtlong_version }}. Adapters were then removed from the filtered reads using porechop v{{ porechop_version }}. 
Human reads removal: Human reads were removed from the quality controlled reads using kraken2 v{{ kraken2_version }}. In short, human reads were identified and removed from the raw reads using kraken2 v{{ kraken2_version }} against a human genome reference database that was constructed from NCBI's RefSeq {{ human_genome_version }}. The database was constructed by running the kraken2 build command with the following parameter set --no-masking, kmer-length 35 and minimizer-length 31. 
{% if sample_type == "low_biomass" %}
Blanks reads removal: Blank / negative control samples were assembled using Flye v{{ flye_version }}. Human removed reads were decontaminated by mapping them to the assembled blank contigs using minimap2 v{{ minimap2_version }} then unmapped/uncontaminated reads filtered out using samtools fastq (samtools v{{ samtools_version }}) by setting the -f parameter to 4 to retain only unmapped reads. 
{% endif %}
Read-based processing: taxonomy assignment of {{ read_type }} reads was performed with Kraken2 v{{ kraken2_version }} and Kaiju v{{ kaiju_version }}. The resulting assignments were visualized as krona plots using krona v{{ krona_version }} and as barplots in R (version {{ r_version }}) using tidyverse v{{ tidyverse_version }}. 
Assembly-based analysis: {{ read_type }} reads were assembled with Flye v{{ flye_version}}. Genes were called with prodigal v{{ prodigal_version }}. Taxonomic classification of genes and contigs was performed with CAT v{{ cat_version }}. Functional annotation was done with KOFamScan v{{ kofamscan_version }}. Reads were mapped to assemblies with minimap2 v{{ minimap2_version }}, and coverage information was extracted for reads and contigs with samtools v{{ samtools_version }} and bbmap v{{ bbtools_version }}. Binning of contigs was performed with metabat2 v{{ metabat_version }}. Bins were summarized with bit v{{ bit_version }} and estimates of bin quality were generated with checkm v{{ checkm_version }}. High-quality bins (greater than 90% est. completeness and less than 10% est. redundancy) were taxonomically classified with GTDB-Tk v{{ gtdbtk_version }} as MAGs (Meta Assembled Genomes).
