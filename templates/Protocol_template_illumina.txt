Data were processed as described in GL-DPPD-{{ pipeline_number }}{{ pipeline_version }} (https://github.com/nasa/GeneLab_Data_Processing/blob/master/{{ workflow_type }}/Pipeline_GL-DPPD-{{ pipeline_number }}_Versions/GL-DPPD-{{ pipeline_number }}{{ pipeline_version }}.md) using workflow NF_MetagenomeSeq v{{ workflow_version }} (https://github.com/nasa/GeneLab_Metagenomics_Workflow/blob/v{{ workflow_version }}/README.md). 
Quality assessment: Quality assessment of raw (human-removed), filtered, and blanks-removed reads was performed with FastQC v{{ fastqc_version }} and reports summarized with MultiQC v{{ multiqc_version }}. 
Quality control: Two rounds of FASTP v{{ fastp_version }} were run to quality filter and remove adapters from the raw reads. First, raw reads were filtered by quality (Phred quality >= 20) and length (>=50bp), and adapters auto detected then removed using FASTP v{{ fastp_version }}. Next, PolyG sequences were detected and removed by running FASTP again on the quality filtered reads after setting FASTP’s --trim_poly_g flag. 
{% if sample_type == "low_biomass" %}
Blanks reads removal: negative control samples were assembled using Spades v{{ spades_version }}. Quality controlled reads were decontaminated by mapping them to the assembled blank contigs then unmapped/uncontaminated reads filtered out using bowtie2 v{{ bowtie2_version }} by setting the parameters --very-sensitive-local and --un-conc-gz to retain only unmapped reads. 
{% endif %}
Read-based processing: taxonomy assignment of {{ read_type }} reads was performed with Metaphlan v{{ metaphlan_version }}, Kraken2 v{{ kraken2_version }} and Kaiju v{{ kaiju_version }}. The resulting assignments were visualized as krona plots using krona v{{ krona_version }} and as barplots in R (version {{ r_version }}) using tidyverse v{{ tidyverse_version }}. 
Assembly-based analysis: {{ read_type }} reads were assembled with megahit v{{ megahit_version}}. Genes were called with prodigal v{{ prodigal_version }}. Taxonomic classification of genes and contigs was performed with CAT v{{ cat_version }}. Functional annotation was done with KOFamScan v{{ kofamscan_version }}. Reads were mapped to assemblies with bowtie2 v{{ bowtie2_version }}, and coverage information was extracted for reads and contigs with samtools v{{ samtools_version }} and bbmap v{{ bbtools_version }}. Binning of contigs was performed with metabat2 v{{ metabat_version }}. Bins were summarized with bit v{{ bit_version }} and estimates of bin quality were generated with checkm v{{ checkm_version }}. High-quality bins (greater than 90% est. completeness and less than 10% est. redundancy) were taxonomically classified with gtdb-tk v{{ gtdbtk_version }} as MAGs (Meta Assembled Genomes).
